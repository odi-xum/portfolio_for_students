📖 Как импортировать студентов из JSON-файла

📌 Что понадобится

  • Файл в формате .json (UTF-8)
  • Список студентов с логинами и паролями
  • Названия групп должны точно совпадать с теми, что уже созданы в системе (например, ИСП-Б-2022)

📝 Формат JSON

[
  {
    "username": "petrov",
    "password": "111",
    "role": "student",
    "group": "ИСП-Б-2022"
  },
  {
    "username": "sidorova",
    "password": "password123",
    "role": "student",
    "group": "ИСП-К-2022"
  }
]

👣 Пошаговый порядок

  1. На странице «Группы» создайте нужные специальности и учебные группы.
  2. Подготовьте JSON-файл — логин, пароль (по умолчанию 111), роль всегда "student", группа — точное название из системы.
  3. На странице «Пользователи» найдите блок «Импорт студентов из JSON».
  4. Нажмите «Выберите файл», укажите ваш .json и нажмите «Импортировать».
  5. Система обработает файл: ✅ новых студентов добавит, ⏭️ уже существующих (с тем же логином) пропустит.
  6. Проверьте результат в таблице пользователей.
⚠️ Важно:
  • Название группы в JSON должно совпадать с названием в БД (например, ИСП-Б-2022, а не ИСП-41).
  • Пароль можно не указывать — будет установлен 111 по умолчанию.
  • Нельзя повторно импортировать одного студента — система пропустит дубликаты по логину.
  • Остальные роли (куратор, комиссия) добавляются вручную через форму «Добавить пользователя».
